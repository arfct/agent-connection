The instructions a person follows to connect an agent to a product, and the ones the agent reads, are generated by agent-connection from a single table, so that the two agree. The table has seven entries: Claude, ChatGPT, Gemini, Muse, Cursor, VS Code, and a General entry for any other MCP client or the REST API.

A product describes what it has once, namely its MCP server, REST API, OpenAPI document, skill file and settings page. From that description the JavaScript library returns the setup steps for each host, a markdown guide to serve at /llms.txt, and the same guide as an HTML page for a browser that opens the MCP address.

The `<agent-connection>` web component draws the steps as a settings panel, with tabs for Claude, ChatGPT, Gemini, Muse and General and a More menu that holds Cursor and VS Code. Those two each get a one-click install link, while Muse, which has no MCP menu, is connected by one sentence for the person to say to it. A second module builds a ChatGPT app submission from the tool list a product's MCP server serves. The library installs from its git repository and has no build step.
